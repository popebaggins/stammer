# Research: What modulation does the original Reverse Mode C have?

## Question

The Chase Bliss Reverse Mode C field guide mentions modulation. We need to know:
- What type of modulation? (LFO, envelope follower, expression pedal input, parameter randomization, something else?)
- Is modulation essential to the pedal's character, or optional?
- If LFO: what waveforms? (sine, triangle, square, random?)
- What's the modulation speed/depth range?
- Does modulation apply to the reverse buffer, the delay stage, or both?

This affects whether modulation is in MVP or post-MVP, and how to implement it.
